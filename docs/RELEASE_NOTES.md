Free Bangla phonetic keyboard for macOS 11+ (Apple Silicon and Intel).

**Install** (Terminal, no admin password):

```
curl -fsSL https://raw.githubusercontent.com/amerganim/MacOSBanglaKeyboard/main/scripts/install.sh | bash
```

or download the `.pkg` below (unsigned: approve it in System Settings → Privacy & Security → Open Anyway).

Then add it once: System Settings → Keyboard → Input Sources → Edit… → + → Bangla → **Amader Bangla Keyboard**.

- Same phonetic engine and key map as the Windows version (`amar sOnar bangla` → আমার সোনার বাংলা)
- Word suggestions (~65k words) that learn what you pick
- Control+Shift+B toggles Bangla / English
- Typing guide in the input menu
